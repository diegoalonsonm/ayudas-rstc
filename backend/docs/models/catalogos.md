# Catálogos

Todos incluyen `id`, `codigo`, `nombre` y campos comunes. Borrado lógico (no físico).

- `tiposDocumento`
- `sexos`, `gradosAcademicos`, `parentescos` (con `ordenPresentacion`)
- `rangosIngreso` (`montoMinimo`, `montoMaximo`, `ordenPresentacion`)
- `tiposVivienda`, `tiposTenencia`, `condicionesVivienda`
- `tiposAyuda` (`requiereDetalle`)
- `cantones`, `distritos` (`cantonId`), `barrios` (`distritoId`)
